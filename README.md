# نظام إدارة أثر (Athar Management System)

نظام متكامل لإدارة المشتريات والمبيعات والمخزون تم تطويره باستخدام إطار عمل **Flutter**. يتميز النظام بدعم العمل بدون إنترنت (Offline-First)، وإدارة كاملة للفواتير والعملاء والموردين، وتقارير وإحصائيات متقدمة مع توثيق أكاديمي شامل.

---

## 📁 هيكلية المشروع (Project Structure)

```text
مشروع اداره/
│
├── flutter_app/                        # الكود المصدري لتطبيق فلاتر
│   ├── lib/                           # شاشات ونماذج وقواعد بيانات التطبيق
│   ├── assets/                        # الأيقونات والخطوط والصور
│   ├── android/ & ios/ & web/         # إعدادات المنصات المختلفة
│   └── test/                          # اختبارات الوحدة والتكامل
│
├── تقرير_مشروع_إدارة_أثر.pdf          # التقرير الأكاديمي الشامل للمشروع (عربي)
├── Athar_Project_Academic_Report.pdf  # Comprehensive Academic Report (English)
├── report.html                        # تقرير تفاعلي بصيغة HTML
├── report_assets/                     # المخططات البيانية والصور التوضيحية للتقرير
└── تطبيق_إدارة_أثر.apk                # نسخة التطبيق الجاهزة للتثبيت على نظام أندرويد
```

## ✨ المميزات الرئيسية (Key Features)

1. **إدارة المشتريات والمبيعات**:
   - تسجيل فواتير الشراء والبيع مع حساب الضريبة والخصم تلقائياً.
   - تتبع حالات الدفع (مدفوع بالكامل، جزئي، آجل).
   - طباعة وتصدير الفواتير كملفات PDF أنيقة.

2. **إدارة المخزون والمنتجات**:
   - متابعة دقيقة لحركة المنتجات ومستويات المخزون.
   - تنبيهات انخفاض المخزون وصلاحية المنتجات.
   - دعم الباركود لتسريع العمليات.

3. **إدارة العملاء والموردين**:
   - سجل شامل لبيانات العملاء والموردين وأرصدتهم المالية.
   - متابعة الديون والمستحقات وجدولة السداد.

4. **لوحة تحكم وتقارير تحليلية**:
   - رسوم بيانية تفاعلية لحجم المبيعات والأرباح الشهرية والسنوية.
   - تقارير تفصيلية جاهزة للطباعة والتصدير.

5. **أمان وموثوقية البيانات**:
   - قاعدة بيانات محلية سريعة ومحمية تدعم العمل بدون الحاجة للاتصال بالإنترنت.
   - ميزة النسخ الاحتياطي واستعادة البيانات.

## 🚀 متطلبات التشغيل والبدء (Getting Started)

### المتطلبات الأساسية:
- [Flutter SDK](https://flutter.dev/) (الإصدار 3.0 فما فوق)
- [Dart SDK](https://dart.dev/)
- أندرويد ستوديو (Android Studio) أو VS Code

### خطوات التشغيل:
```bash
# الدخول إلى مجلد التطبيق
cd flutter_app

# تحميل الحزم والمكتبات
flutter pub get

# تشغيل التطبيق في وضع التطوير
flutter run
```
